# Project 131

## Project Title

Automated Code Review and Defect Prediction via Graph-based Dependency Analysis for Refactoring, Applied to Enterprise Legacy System Modernization

## Domain

Software Engineering & DevOps

## Core Objectives

1. Extract dependencies from source code.
2. Build a graph representing software dependencies.
3. Calculate graph and code-quality metrics.
4. Identify potentially defect-prone modules.
5. Recommend risk-aware refactoring.
6. Generate a dependency-aware modernization plan.
7. Produce understandable analysis reports.
8. Validate changes in a controlled environment.

## Development Principles

- Build incrementally.
- Keep core analysis independent of external LLM APIs.
- Use explainable metrics and established tools.
- Test every component before adding the next.
- Use Git to support seamless migration from Termux to a laptop.

## Initial Milestone

Build and test a dependency graph using Python source files.
